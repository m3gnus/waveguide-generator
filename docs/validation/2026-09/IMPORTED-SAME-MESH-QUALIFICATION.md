## Reproduce

On a macOS host with Metal and a provisioned BEAT CPU runtime, with an
interpreter whose HornLab modules match `pins.json`, from the repository root:

```bash
env -u JULIA_DEPOT_PATH \
  HORNLAB_BEAT_FORCE_CPU=1 \
  HORNLAB_BEAT_JULIA="<installed Julia 1.12.6>/bin/julia" \
  python scripts/qualify_imported_same_mesh.py \
    --json docs/validation/2026-09/imported-same-mesh-qualification.json \
    --markdown docs/validation/2026-09/IMPORTED-SAME-MESH-QUALIFICATION.md
```

The run needs both engines; with either missing it exits 2.
`scripts/tests/test_qualify_imported_same_mesh.py` checks the harness itself
without a solver, and `WG2_QUALIFY_IMPORTED=1` adds the real run to it.

`hornlab-waveguide-mesher` down, the two paragraphs after the engine list, the
note on the least order, and the unjudged-row labels were added to the generated
record. No measured value was changed.

## Deliverables

1. **Design tokens** — `src/styles/tokens.css`: port the sketch's `:root` + `[data-theme="light"]` custom properties faithfully (colors, radii, spacing scale, type scale, the RGB-triple accent pattern). Wire into Tailwind v4 via `@theme` so utilities use the tokens. Theme toggle flips `data-theme` on `<html>` (persist in localStorage).
2. **Shell layout** (`src/shell/`): top bar (app identity, design filename chip with unsaved dot, undo/redo buttons wired to the store, theme toggle, disabled Solve button, command-affordance placeholder); **dockview** workspace with panels matching the sketch's regions: Parameters (left), Viewport (center), Results (bottom/right), Jobs (right); layout persisted to localStorage with a reset action; status bar (engine badge from `/api/capabilities` via react-query, connection state from the WS manager, placeholder mesh stats).
3. **Design store** (`src/stores/design.ts`): zustand + zundo implementing plan §4.2 exactly: `designRevision` increments on every committed mutation; undo/redo/load bump revision and cancel pending debounce timers (expose a `subscribeRevision` hook the WS manager uses); grouped drag transactions = one undo step (begin/endDrag API). Seed state: a representative R-OSSE design matching the sketch's values.
4. **Param panel** (`src/design/`): collapsible sections per the sketch (Profile R-OSSE fields, Source, Symmetry, Enclosure, Mesh) using a reusable `NumberField` (unit suffix, drag-to-adjust on label, invalid styling) bound to the store with per-field commit → revision bump. Family dropdown switches visible field sets (OSSE/R-OSSE only for now; ICW/FREEFORM show a "coming in a later phase" stub section).
5. **WS + frame plumbing** (`src/api/`): `frame.ts` — thin typed wrapper importing the existing decoder from `../../shared/js/frame.mjs` (vite `fs.allow` already permits it); `previewSocket.ts` — WS manager per `../docs/WS-PROTOCOL.md`: connect `/ws/preview`, handle `hello`/epoch, assign seq, send full design on revision change (leading+trailing debounce ~33 ms), one pending client-side, drop stale-epoch/stale-revision frames, `dropped`/`error` handling, reconnect with backoff + resend current state. **Viewport panel for this batch: a placeholder that renders the LATEST frame's header stats (revision, LOD, evalMs, surface roles + vertex counts) as styled text + the display-mode toolbar chrome from the sketch (non-functional). No three.js rendering yet.**
6. **Tests** (vitest): store revision semantics (undo-during-drag cancels timers; grouped drag = one undo step; revision monotonic), previewSocket state machine against a mock WebSocket (hello/epoch, stale-revision drop, reconnect resend), frame.ts decodes a real fixture from `../../shared/frame-fixtures/` (read via fs in the test), NumberField commit behavior.
7. `npm run build` and `npx vitest run` both green; no console errors in dev.

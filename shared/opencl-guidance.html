CPU OpenCL runtime

On computers without a supported graphics-card solver, WG's BEMPP solver runs on the CPU. Installing a CPU OpenCL runtime makes it much faster. It still works without one, more slowly.

  • Intel CPU OpenCL runtime

    Intel's CPU runtime officially supports Intel processors; it has also worked on AMD processors in our testing. If no OpenCL device works, WG falls back to its slower numba engine.

PoCL on Windows shows up as an OpenCL device but computes nothing, so installing it does not help.
